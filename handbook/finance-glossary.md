# Mavis 投资分析词典

> **目的:** Mavis 框架里用到的金融术语速查。
> **⚠️ 已彻底删除的概念 (禁止复活):** DCF L / PEG / OBV / fflow / EPS 机构一致预期 (预测值)。
> 估值只看 **PE (静态) + ROC/EY/毛利率/杠杆**, 全部用已审计财报算。

---

## 1. 基础术语

| 术语 | 公式 / 说明 |
|---|---|
| **市值** | 总股本 × 当前股价 |
| **EPS** | 净利润 / 总股本 (本项目只用**已审计真实值**, 不用机构预测) |
| **PE (静态)** | 市值 / TTM 净利润 — 越低越便宜; 周期底部 PE 虚高不可信 |
| **ROE** | 净利润 / 股东权益 — 活过滤门槛 **>5%** (全市场中位仅 2.29%) |
| **ROC** | TTM EBIT / (NWC + FA) — 投入资本 = 净营运资本 + 固定资产; NWC+FA < 5亿 剔除 (分母过小假阳性) |
| **EY (盈利收益率)** | TTM EBIT / EV — EV = 市值 + 净债务 (**不是** 净利/市值) |
| **FCF** | 经营性现金流 (OCF) - 资本支出 (CapEx) |
| **毛利率** | (营收 - 营业成本) / 营收 |

### PE 口径说明
- **PE TTM** = 股价 / 最近 12 个月真实 EPS → **本项目用这个**
- **Forward PE** = 股价 / 未来 12 个月预测 EPS → 已删, 不用预测值

### OCF / NI 比率 (现金质量)
```
OCF / 净利润 > 100% 为佳 (说明利润有真实现金支撑)
持续 < 80% → 警惕 (利润是应收堆积)
```

## 2. Mavis 决策框架速查

| 框架要素 | 含义 | 来源 |
|---|---|---|
| PE (静态) | 近期估值是否合理 | 已审计 TTM 财报 |
| ROC / EY | 盈利质量 (真钱还是账面钱) | 已审计 TTM 财报 |
| 卡点强度 | 供应链不可替代程度 | 行业分析 |
| 龙头评分 | 0-14 分, ≥11 才是真龙头 | 四维评分 |

> ⚠️ 旧的 **"L / 可达利润" 轴 (DCF 隐含终局利润) 已随 DCF 一起删除, 禁止复活**。

## 4. 叙事切换 — PE 重估

**估值切换类型 (A 股常见):**
- 行业身份切换: 例 特变电工 电力设备 → AI 数据中心卖水
- 客户结构切换: 例 立讯 Apple 代工 → AI 服务器 ODM

**数学:**
```
旧叙事 PE = 12x, 新叙事 PE = 25x
估值贡献 = 25/12 = 2.08x (+108%)
加上业绩 1.5x 增长 → 翻番 = 2x × 1.5x = 3x
```

**触发条件 (4 维全满足才算估值切换型机会):**
1. 一致预期 EPS 5 年 CAGR ≥ 15%
2. 当前 PE < 历史 50% 分位 (留扩张空间)
3. 在 AI/新能源/半导体/机器人主线上
4. 龙头评分 ≥ 11/14

**陷阱:**
- 切换没兑现 → 叙事讲得动听但订单/业绩没兑现, 估值回吐
- 切换到位后估值已 Priced → 空间用完, 只能吃业绩增长
- 叙事破裂 → 从 25x 跌回 12x = -52% 跌幅

## 5. 数学工具速查

| 工具 | 公式 | 用途 |
|---|---|---|
| **CAGR** | `(V_end/V_start)^(1/n) - 1` | 年化复合增长率 |
| **Z 分数** | `(值 - 平均) / σ` | 标准化偏离 |
| **PE-Band** | `(PE_today - PE_min) / (PE_max - PE_min)` | PE 历史位置 |
