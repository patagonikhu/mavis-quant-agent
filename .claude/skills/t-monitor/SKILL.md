# t-monitor: T 位置监控 + Web 搜索 (跨数据源, v2.3)

## 触发

```
/t-monitor                       # 默认: events.json + watchlist.json 跨扫 + WebSearch
/t-monitor --no-news             # 关闭 WebSearch (零数据拉取模式)
/t-monitor --window 6            # 扫描未来 6 个月窗口 (默认 ±3)
/t-monitor --no-news --window 6  # 零数据 + 6 月窗口
```

**v2.3 设计原则升级:** 同时读 `events.json` (事件) + `watchlist.json` (关注股), 三段式输出 (交集 / 仅 watchlist / 仅 events), 不漏掉任何关注的股。

## 工作流

### 1. 读上下文 (双数据源)

- `CLAUDE.md`（必读, 决策矩阵 + 输出格式）
- `docs/analysis-framework.md#t-phases`（**必读**, 阶段判定算法）
- `data/events.json`（**必读**, 全部事件）
- `data/watchlist.json`（**必读**, 全部关注股, v2.3 新增为必读）
- `data/sectors.json`（按需, 用于交叉检查）

### 2. 三段式分类 (v2.3 核心逻辑)

对每条事件和每只 watchlist 股票, 分到三个桶:

| 桶 | 含义 | 例子 |
|---|---|---|
| **A) 交集** | watchlist + events 都收录 | 688017 绿的谐波 (两边都有) |
| **B) 仅 watchlist** | watchlist 有, events 没有 | 300748 金力永磁 (关心但没事件) |
| **C) 仅 events** | events 有, watchlist 没有 | 002886 沃特股份 (有事件但不关心) |

### 3. 算 T 位置

对 A 桶和 C 桶的事件:
```
T = (event_date - today) / 30
today = datetime.now().strftime('%Y-%m-%d')  # 动态获取当天日期
```

对 B 桶的股票: T = "N/A", 备注"未识别 T 点, 建议补事件"。

按 T 位置分组:

| 阶段 | T 范围 | 操作建议 | 颜色 |
|---|---|---|---|
| T-12 ~ T-9 | 故事初期 | 观察, 小仓位 | ⚪ |
| T-6 ~ T-3 | **最佳埋伏** | 加仓 | 🟢 |
| T-1 ~ T+0 | **甜蜜窗口** | 再加 1-2% | 🟢 |
| T+0 ~ T+3 | 主升浪 | 全仓持有 | 🟡 |
| T+3 ~ T+6 | **顶部信号** | 减仓 1/3 | 🔴 |
| T+6 ~ T+9 | **跑路窗口** | 再减 1/3 | 🔴 |
| T+12+ | 退潮 | 清仓 | ⛔ |

## 5. Web 搜索 (默认开启, v2.3 扩展范围)

**v2.3 关键改进:** WebSearch 现在覆盖三种目标:

| 目标 | 触发条件 | 典型数量 |
|---|---|---|
| **A) 交集 + 窗口内** | T 在 ±3 月 或 `confidence < 0.8` | 5-8 |
| **B) 仅 watchlist** (新) | 全部 (因为没事件, 最需要发现) | 6 |
| **C) 仅 events + 窗口内** | T 在 ±3 月 或 `confidence < 0.8` | 1-2 |

**典型总 WebSearch 调用:** 12-16 次 (12 只 watchlist + 2-4 个窗口内 events)

**搜索 query 模板:**
- `"{name} {sector} 2026 最新"`
- `"<code> <name> 公告"`
- `"{name} 量产 订单 财报"`

**严格筛选标准:**
- ✅ 财报披露日 / 大订单 / 政策落地 / 产品发布
- ❌ 分析师观点 / 媒体猜测 / 股价评论

**性能注意:**
- 典型 watchlist 12 只 + 窗口内事件 4-6 → 12-16 WebSearch 调用
- Token 增量: ~30-50K
- `--no-news`: 0 调用 (零数据拉取模式)
- 频率建议: 隔天可跑 (Token 消耗可控)

## 注意事项

- v2.3 三段式输出: A 交集 / B 仅 watchlist / C 仅 events — 不漏任何关注的股
- B 桶股 (无事件) 触发 WebSearch — 因为最需要发现新 T 点
- C 桶股 (仅 events) 提示"未在 watchlist,考虑加进"
- 默认只显示未来 ±3 个月的窗口, 但完整表格全部列出
- 反向事件 (impact=负) 即使不在窗口内也要显示, 单独一段
- confidence < 0.5 的事件在备注里标"低信心, 仅参考"
- 报告控制在 80 行内 (因为三段式比单段更长)
- **WebSearch 默认开启** — 不想要自动拉数据的用户传 `--no-news`
- **WebSearch 不自动写 events.json** — 必须用户 y/N 确认才加
- **WebSearch 的噪音:** 90% 是媒体猜测, 真事件不到 10%。LLM 必须严格筛选
