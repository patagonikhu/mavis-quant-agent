## 5.4 📋 三层仓位策略模板 v4 (2026-07-17 修订)

> **核心原则：三个级别中枢永远都要算，各管一层仓位，含义随价格位置变化**

### 三级别中枢对应关系

```
周线中枢（每段1-3个月）  → 管底仓
日线中枢（每段1-4周）    → 管中仓
60分中枢（每段数小时）   → 管波动仓
```

### 中枢含义（三种情况）

- **上方**：下沿=止损，目标=上沿+宽度（等幅）
- **内部**：下沿=止损，上沿=突破目标，等方向
- **下方**：下沿=第一目标/阻力，止损用结构低点

### 三层仓位（v4）

| 层级 | 仓位 | 止损 | 离场 |
|---|---|---|---|
| 逆势仓 | 10-15% | 结构低点-ATR | 跌破即割 |
| 底仓 | 25-30% | 底背驰确认低点/周线下沿 | 周线背驰 |
| 中仓 | 20-25% | 日线中枢下沿 | 日线顶背驰 |
| 波动仓 | 20-25% | 60分中枢下沿 | MA20偏离>30% |

### 进场时机与止损阶梯

**中枢下方时（逆势/底仓）：** PEG<1.0+RSI<25+止跌信号→逆势仓；日线底背驰+3天不创新低→底仓；站上日线中枢下沿→中仓；60分底背驰→波动仓
**中枢上方时（加仓）：** 周线中枢上沿回踩→底仓加；日线上沿回踩→中仓加；60分底背驰→波动仓加

**止损阶梯：** 结构低点-ATR→逆势仓 / 60分下沿→波动仓 / 日线下沿→中仓 / 周线下沿→底仓

## 5.5 🏗️ 中枢位置判断 + 重心分析 (2026-07-17 修订)

> **完整版：涵盖价格在中枢任何位置的操作建议，包含建仓和持仓两种状态**

### 完整十五种组合（周线×日线×60分）

**核心规则：看哪个级别就管哪层仓位。** 状态判断：
- 🟢 三级全上方 → 主升浪，持有/加波动仓
- 🟡 周上/日内 → 健康整理，持有等突破
- 🟠 周上/日下 → 中线危险，减中仓
- 🔴 三级全下方 → 底仓减至10%，等止跌信号建逆势仓
- 🟡 三级全下/60分修复 → 加底仓；三级全下/日线修复 → 加中仓

### 逃顶完整策略（两层）

```
第一层：顶背驰（衰竭顶）
  ⭐趋势顶背驰 = 两个中枢 + 中枢外 + 段面积<50% → 减中仓1/3
  🔵普通顶背驰 = 段面积<50% → 减波动仓

第二层：MA20偏离>20%（强势顶，满足前提才有效）
  前提：板块非主升浪加速段 + 价格在日线中枢上方
  失效：CPO/AI链主升浪中
  有效：新能源/传统行业/半导体设备等非主升浪高位
  → 减波动仓；双重确认时减中仓1/2
```

### 止损阶梯（有仓位时）

- 中枢上方：60分下沿→波动仓减 / 日线下沿→中仓减 / 周线下沿→底仓减
- 中枢下方：结构低点-ATR→逆势仓减 / 底背驰低点跌破→底仓减半


## 5.6 📐 入场三要素 (2026-07-17 固化)

> **核心结论：中枢给位置，背驰给时机，止跌信号给确认**
> **三个缺一不可：只有位置没有背驰→接飞刀；只有背驰没有位置→没有目标；只有止跌没有背驰→可能是假反弹**

### 三要素定义

**要素一：中枢位置（在哪里进）**
- 中枢内部 → 支撑已知，可建仓；中枢上方回踩 → 加仓点
- 周线中枢→底仓 / 日线中枢→中仓 / 60分中枢→波动仓

**要素二：背驰（什么时候进）**
- 底背驰：回调段2 MACD面积 < 段1面积×50% 且价格未创新低
- 60分底背驰→波动仓 / 日线底背驰→中仓底仓 / 周线底背驰→大底必加
- 注意：半导体设备/AI链背驰失效，用MA20偏离>30%替代

**要素三：止跌信号（确认进场）**
- ① 缩量（成交<20日均量×0.85）② 长下影（>40%）③ 次日不创新低
- 三个同时满足 → 最强；两个满足 → 减半建；一个 → 等
- 实证 CPO 3-5月：91% 命中率 (10/11)

### 入场组合规则

三个都满足→全建；两个→减半建；一个→等。各笔：第1笔(5%)周线中枢内+止跌；第2笔(10%)60分底背驰+止跌；第3笔(15%)60分中枢站稳+日线底背驰；第4笔(10%)日线中枢站稳


## 5.7 🎯 60分 顶底背驰 × 市况 × 板块热度 组合矩阵 (2026-07-19 实证固化, n=2500+)

> **来源:** watchlist 70 只票 × Sina 60分 K线 (datalen=3795 上限, 2022-08~2026-07, 3.8年)
> **总样本:** 1215 个顶背驰 + 1342 个底背驰
> **核心结论:** 60分 背驰 **不是通用信号**, 必须按 市况 × 板块 × 个股位置 三维过滤

### 5.7.1 总样本胜率

底背驰 5d 涨率 63% / 顶背驰 5d 跌率 66%（n=2500+，3.8年）

### 5.7.2 按市况分组 (上证 MA60 偏离 ±5% 阈值)

| 市况 | 顶背驰 5d 跌率 | 底背驰 5d 涨率 | 底背驰 10d |
|---|---|---|---|
| 🟢 **牛市** (MA60>+5%) | 63% | **75%** ⭐ | **80%** ⭐⭐ |
| 🟡 **震荡** (-5%~+5%) | 66% | 62% | 59% |
| 🔴 **熊市** (MA60<-5%) | **70%** | **72%** | **77%** ⭐⭐ |

**反直觉:** 牛市底背驰 10d 80%涨率 / 熊市急跌后反弹 20d 最强但 5d 内必须卖 / 震荡市信号最不可靠

### 5.7.3 关键组合

- 弱势低位 (MA60<-20%) + 震荡市 = 不抄底（5d涨率仅25%，强制规则）

- 震荡市 + 个股中性 → 标准（62%）

### 5.7.6 强制执行规则 (高于矩阵)

1. **震荡市 + 个股MA60<-20%**: **不抄底**（5d涨率25%）
2. **熊市 + 板块过热**: **清仓**

4. **强信号板块**（≥70%）: 60分底背驰可作主要建仓信号
5. **弱信号板块**（<50%）: 底背驰失效，用fflow+PEG

1. 上证MA60偏离 → 牛/震荡/熊 → 仓位上限
