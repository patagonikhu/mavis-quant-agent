## 估值方法 (v3.0 公式 + 实数据)

每只标的完整估值见 `docs/analyze-{code}.md`, 含:
- 数据来源 (E0/E1/E2/E3 + NP0/NP1/NP2/NP3 + 9 行表格)
- PEG 计算 5 步 (Forward PE → g → PEG → DCF L → 风险检查)
- 评级 (🥇🥇 / 🥇 / 🥈 / 🥉 / ⚠️ / ❌)

**公式:** `PEG = Forward PE / g`
- `Forward PE = P / E1`  (本财年一致预期 EPS)
- `g = (NP1 / NP0 - 1) × 100%`  (本财年净利润预期 vs 上财年实际)
