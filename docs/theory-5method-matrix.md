# 5 方法 × 3 周期 互补理论框架 (2026-07-24 固化)

> 📌 **来源**: Kurt 提出"用 5 套方法 + 3 个时间周期 = 15 场景矩阵互补, 覆盖所有场景"
> 🎯 **目的**: 单套方法都有盲区, 多套互补 = 高信念信号
> 🔧 **实现**: `tools/wyckoff.py` + `tools/smc.py` + `tools/resonance.py` + `tools/signals_5method.py`

## 1. 5 大方法核心

| 方法 | 一句话 | 答什么问题 | 盲区 |
|---|---|---|---|
| **缠论** | 走势分中枢+段+背驰 | 趋势如何分段 | ❌ 主升浪晚段失效 |
| **威科夫** | 主力建仓→派发 4 阶段 | 谁在买/卖 (主力) | ❌ 主观判断, 量化难 |
| **SMC** | 找主力订单块/流动性扫 | 主力订单在哪 | ❌ OB 主观, 震荡市假信号多 |
| **量价** | 量是真是假 (齐升 vs 背离) | 这波上涨是真是假 | ❌ 单日噪音, 3 日连续才可信 |
| **多市场共振** | 个股+板块+大盘方向同 | 这次行情是板块级还是个股级 | ❌ 三方同向才有效, 1-2 个不共振信号弱 |

**互补逻辑**:
- 缠论 = 空间结构 (中枢/段)
- 威科夫 = 时间阶段 (建仓到派发)
- SMC = 订单细节 (OB/FVG/流动性)
- 量价 = 动作验证 (真突破 vs 假突破)
- 多市场共振 = 环境验证 (大盘支持不支持)

**5 套方法 = 5 个独立维度的"过滤器", 多重共振 = 高信念**。

## 2. 时间周期 × 5 方法 分工

| 周期 | 缠论 | 威科夫 | SMC | 量价 | 多市场共振 |
|---|---|---|---|---|---|
| **60分** (数小时~2天) | 60分中枢+底背驰 (精确进场) | 阶段C/D | FVG/流动性扫 | 量比 | 板块联动 |
| **日线** (1-4周) | 日线中枢+背驰 (波段) | 阶段B→D→E | OB/突破回踩 | 量价齐升/背离 | 风格切换 |
| **周线** (1-3月) | 周线中枢+主升浪判断 | 阶段A 全周期 | BOS/MSS 趋势 | 月线量能 | 牛熊转换 |

**关键原则**: **高级别定方向, 低级别定时机**
- 周线: 是否值得建仓 (4 问 + T 框架 + 主升浪阶段)
- 日线: 建仓类型 (中枢位置 + 段结构)
- 60分: 精确买入点 (背驰 + 止跌信号)

## 4. 共振判断规则 (高信念信号)

```
5 重共振 (最高信念): 缠论背驰 + 威科夫阶段 + SMC OB + 量价齐升 + 多市场同向
4 重共振             : 缺 1 个, 仍可建仓
3 重共振             : 标准信号, 减半仓位
2 重共振             : 观察, 不操作
1 重共振             : 假信号概率高, 放弃
0 重共振             : 不要操作
```

**5 重极罕见** (1-2 年一次), **3 重共振 = 实战可靠标准**。

## 8. 跨周期决策矩阵 (9 种组合, 矛盾处理)

> **核心原则: 高级别定方向 (1.5x), 中级别定时机 (1.0x), 低级别定进场 (0.5x)**

### 8.1 跨周期权重

```
周线 (主升浪方向): 1.5x   ← 决定能不能做
日线 (波段位置):   1.0x   ← 决定什么时候做
60分 (短线进出):   0.5x   ← 决定具体怎么做
```

### 8.2 9 种组合决策表

| 周线 | 日线 | 60分 | 状态 | 操作 |
|---|---|---|---|---|
| ✅YES | ✅YES | ✅YES | **全周期共振** | 🥇 大仓位建仓 |
| ✅YES | ✅YES | ⚪NO | 高/中级共振 | 🥈 建仓, 等 60分止跌加仓 |
| ✅YES | ⚪NO | ✅YES | 短线反弹 (陷阱) | 🟡 暂不动, 等日线确认 |
| ✅YES | ⚪NO | ⚪NO | 高位震荡 | 🟡 持有, 不建仓 |
| ⚪NO | ✅YES | ✅YES | **陷阱** | 🟠 警惕, 60分反弹是出货 |
| ⚪NO | ✅YES | ⚪NO | 弱势反弹 | ❌ 不操作 |
| ⚪NO | ⚪NO | ✅YES | 强弩之末 | ❌ 假信号 |
| ❌NO | ✅YES | ✅YES | 趋势反转 | 🔴 减仓 |
| ❌NO | ❌NO | ❌NO | 下跌中 | 🔴 不接刀 |

**符号**:
- ✅ = 该周期有信号 (背驰/支撑/进货等)
- ❌ = 该周期反向信号 (顶背驰/出货/压力)
- ⚪ = 无信号 (中性)

### 8.3 矛盾处理 4 大规则

```
规则 1: 高级别背驰 = 一票否决
  周线顶背驰 → 不管日线/60分多强, 减仓
  周线底背驰 → 强力建仓信号 (可逆日线/60分)

规则 2: 日线无信号 = 不进场
  即使周线强, 日线无信号也不建仓
  日线 0-1 重共振 = 观望

规则 3: 60分反方向 = 不追
  周线+日线多, 60分顶背驰 = 等回调再加仓
  不在 60分顶部追多

规则 4: 跨周期协调一致 = 强信号
  周+日+60分 3 重共振 = 极强信号 (5 重共振)
  背驰方向也 3 级共振 = 极强反转
```

### 8.4 同周期 5 方法权重 (MVP 等权)

```
MVP 阶段: 每个方法 1 分, 共振 0-5 分
  - 简单稳定, 易理解
  - 不需要回测数据
  - 3 重共振 = 标准信号 (不管哪 3 个)

未来加权 (需要回测数据):
  缠论:           1.0x (基础)
  量价:           1.0x (基础, fflow 真实数据)
  威科夫:         0.8x (主观, 误差较大)
  SMC:            0.9x (OB 难识别)
  多市场共振:     1.0x (独立验证, 准)
```

### 8.5 总信号强度公式

```
公式 (MVP):
  total_score = Σ(同周期共振数 × 周期权重系数)
  - 周线: 1.5x
  - 日线: 1.0x
  - 60分: 0.5x

判定:
  total_score ≥ 3.0  → 标准建仓 (🥈)
  total_score ≥ 4.0  → 强建仓 (🥇)
  total_score < 1.5  → 不操作
  1.5 ≤ total < 3.0  → 观察 (🟡)
```

### 8.6 实战案例 (2026-07-24)

#### 京东方A (000725) - 总分 2.5, 🟡观察
