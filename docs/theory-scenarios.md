# 5方法场景 A-E 判定理论 (2026-07-27 固化)

> 📌 **来源**: 5方法×3周期矩阵的"场景分类"判定逻辑, 跟威科夫 3 大阶段是**两套并行的分类体系**
> 🎯 **目的**: 解释"为什么这只票被判场景 D 底部建仓" — 用透明可审计的公式
> 🔧 **实现**: `tools/signals_5method.py` line 328-360 (跟 WyckoffTradingAgent 3 大阶段对齐后, 2026-07-27 修复)

## 1. 两套并行分类 (重要: 不要混!)

| 维度 | 场景 A-E | 威科夫 3 大阶段 |
|---|---|---|
| **算法位置** | `signals_5method.py` | `wyckoff.py` (v4) |
| **取值** | A/B/C/D/E 5 选 1 | Accumulation/Markup/Distribution 3 选 1 |
| **依据** | 威科夫阶段 + MA 偏离 + 缠论背驰 | 250 根斜率 + MA20/MA60 胶着 + sub-event |
| **输出位置** | 报告第一行 `**场景**: D (底部建仓)` | 报告 `## 🟢 主力分析` 和 `威科夫阶段` |
| **方法学** | 综合判定 (互斥 5 选 1) | 单方法判定 (主升/累积/派发) |

**两套体系是互补的**:
- 场景 D (底部建仓) **通常伴随** 威科夫 Accumulation
- 场景 A (主升浪) **可能伴随** 威科夫 Markup 或 Distribution
- 场景 ≠ 威科夫, 但 90% 票会落在 "场景 D + 威 Accumulation" 组合

## 2. 5 个场景的判定公式

```python
# signals_5method.py 修复后 (line 328-360)
wy_stage = wyckoff.get('stage', '?')     # 威科夫 3 大阶段
dev_ma20 = (current_price / MA20 - 1) * 100
dev_ma60 = (current_price / MA60 - 1) * 100

# 5 选 1 互斥 (按优先级)
if wy_stage == 'Markup' and dev_ma20 > 5 and '顶背驰' not in chan_d:
    scene = 'A'   # 主升浪
elif wy_stage == 'Distribution' or ('顶背驰' in chan_d and dev_ma20 > 0):
    scene = 'B'   # 过渡回调
elif wy_stage == '?' and -5 < dev_ma20 < 5:
    scene = 'C'   # 震荡市
elif wy_stage == 'Accumulation' or '底背驰' in chan_d:
    scene = 'D'   # 底部建仓
elif dev_ma60 < -20:
    scene = 'E'   # 弱势股
else:
    # 兜底: 按 MA20 偏离
    if dev_ma20 > 10:    scene = 'A'
    elif dev_ma20 > 0:   scene = 'B'
    elif dev_ma20 > -10: scene = 'C'
    else:                scene = 'D'
```

## 3. 5 个场景的完整定义

### A 主升浪 (加速段)

**判定条件** (任一满足):
- 威科夫 Markup + MA20 偏 +5% + 无顶背驰
- 兜底: MA20 偏 > +10% (即使威科夫没法判定)

**特征**:
- 多头排列 (MA5 > MA20 > MA60)
- 价格突破所有均线
- MACD 面积逐段扩张 (无背驰)
- 主力在派发 (Distribution) 还没开始

**操作**:
- ❌ **禁用缠论背驰** (主升段背驰无效, 改用威科夫 Distribution)
- ✅ 主用威科夫 (盯 Distribution 派发)
- ⚠️ 辅助 SMC OB (突破 OB 站稳 = 续涨信号)

**实战**: 2026-07-27 watchlist 0 只 (市场弱势, 没主升浪)

---

### B 过渡回调 (顶部信号)

**判定条件** (任一满足):
- 威科夫 Distribution (派发阶段)
- 日线顶背驰 + MA20 偏 > 0%

**特征**:
- 段面积衰减 (背驰)
- 量价背离 (价涨量缩)
- OBV 转负
- 主力在卖, 散户在接

**操作**:
- ✅ **主用缠论顶背驰** (顶部最有效)
- ✅ 辅助威科夫 Distribution
- ⚠️ 辅助 SMC OB 压力位

**实战**: 江西铜业 (600362) 7-27 - 顶背驰 + MA20 偏 -0.3% (0 只标准 1 卖信号, 这只算边缘)

---

### C 震荡市 (横盘整理)

**判定条件**:
- 威科夫无法判定 (?) + MA20 偏离 ±5% 中性
- 或兜底: -10% < MA20 偏 < 0%

**特征**:
- 价格在 MA20 上下波动
- 无明确趋势
- 段结构短小, 背驰信号噪音大
- 主力在观望

**操作**:
- ⚠️ **谨慎用缠论背驰** (横盘背驰假信号多)
- ⚠️ 等威科夫 阶段 C (弹簧测试)
- ✅ **主用 SMC-OB** (横盘区间 OB 支撑/压力最有效)

**实战**: 7 只 - 沪电股份/埃斯顿/精测电子/中芯国际/拓荆科技/三环集团/中国巨石

---

### D 底部建仓 (吸筹末段)

**判定条件** (任一满足):
- 威科夫 Accumulation (累积阶段)
- 日线底背驰 (段面积衰减, 趋势反转)

**特征**:
- 价格在 MA20 下方 (-10% ~ -30%)
- 段面积收缩 (底背驰)
- 量价配合: 缩量止跌 + OBV 底背离
- 主力在吸筹, 等待突破

**操作**:
- ✅ **主用缠论底背驰** (吸筹末段最有效)
- ✅ 辅助威科夫 Accumulation
- ⚠️ 辅助 SMC OB 支撑位

**实战** (2026-07-27 watchlist 48 只 = 84%):
- 🥇 阳光电源 3 重共振 (场景 D + 趋势 1 买)
- 🟡 思源/特变/中际旭创/新易盛 等 2 重共振
- ⬜ 其他 1 重假信号 / 0 重不操作

---

### E 弱势股 (长期下跌)

**判定条件**:
- MA60 偏 < -20% (长期远离均线)
- (兜底分支, 优先级最低)

**特征**:
- 长期下跌趋势
- 远离 MA60
- 偶有反弹, 但趋势未变
- 主力已离场, 散户被套

**操作**:
- ❌ 禁用缠论背驰 (弱势股底背驰全是假信号)
- ⚠️ 等威科夫 Spring (弹簧测试) 才是底部
- ✅ **主用 SMC-OB** (找反弹 OB)

**实战** (2026-07-27 watchlist 0 只): 当前 watchlist 没弱势股 (已经剔除了), 但之前 *ST 票经常落这个类别

## 5. 跟威科夫 3 大阶段的对应关系

| 场景 | 常见威科夫阶段 | 不太可能的威科夫阶段 |
|---|---|---|
| **A 主升浪** | Markup (主升中) | Distribution (会进 B) |
| **B 过渡回调** | Distribution (派发) | Accumulation (会进 D) |
| **C 震荡市** | ? 或 Markup 起点 | Distribution / Accumulation 末期 |
| **D 底部建仓** | Accumulation (累积) | Markup (会进 A) |
| **E 弱势股** | Accumulation (寻底中) 或 Distribution 末期 | Markup (会进 A) |

**为什么 90% 票 "场景 D + 威科夫 Accumulation"?**
- 大盘弱势时, 多数票在低位吸筹
- 主力趁低吸筹 → 威科夫判 Accumulation
- 缠论判底背驰 → 场景判 D
- 两者一起: **健康建仓窗口**

## 6. 实战决策流程

### 拿到场景分类后, 立刻问 3 个问题:

**Q1: 场景是 D 吗?**
- ✅ 是 → 用缠论底背驰 + 威科夫 Accumulation (主用方法)
- ❌ 否 → 看是哪个场景, 用对应方法

**Q2: 共振数 ≥ 2 吗?**
- ✅ 是 → 高信念信号, 准备建仓
- ❌ 0-1 重 → 等下一个信号共振

**Q3: 估值 (PEG + L/E3) 健康吗?**
- ✅ PEG < 1.5 + L/E3 < 3 → 估值+技术+基本面 三绿, 强建仓
- ❌ PEG > 2 或 L/E3 > 5 → 估值透支, 不管技术多强都不买

### 实战 阳光电源 7-27:
- 场景 D 底部建仓 ✅
- 共振 3 重 ✅
- PEG 0.82 + L/E3 1.14 双绿 ✅
- 趋势 1 买触发 ¥113.42
- **结论**: 🥇 最强 actionable 买入信号

### 实战 三环集团 7-27:
- 场景 D 底部建仓 (但 1 重共振) ⬜
- 趋势 1 卖触发 ¥100.84
- L/E3 = 5.47 偏贵 ❌
- **结论**: 减仓候选, 矛盾信号不操作

## 8. 实战案例: 阳光电源 7-27

```
5方法矩阵输出:
  场景: D (底部建仓) | 共振: 3 重 | 行动: 🥈 标准建仓

判定链条:
  1. 威科夫阶段 = Accumulation (累积, 100%)
     → 进入第 4 个 if: scene = 'D' ✅
  
  2. 缠论日线 = 趋势 1 买 (2 中枢 + 分型)
     → 触发底背驰信号, 跟威科夫 Accumulation 共振
  
  3. 量价: 5 日主力 +10 亿 (进货)
     → 跟底背驰共振 (3 重)
  
  4. SMC OB 支撑 ¥109.3 (60分)
     → 跟底背驰位置吻合, 4 重共振
  
  5. 多市场共振: 个股-3.7% / 板块+0.0% / 沪深+0.0%
     → 混合 (不共振但不矛盾)
  
  结论: 3 重共振 = 强 actionable 信号
  行动: 🥈 标准建仓 ¥113.42
```

**如果不是 3 重共振 (只有 1 重)**: 会判 ⬜ 假信号, 不操作.
