
### PEG 估值规则 (v3.0)

```
公式: PEG = (P / E1) / g  ← A 派标准
   E1 = 下一财年 EPS 预期 (一致预期均值)
   g  = (E1 / E0 - 1) × 100%  ← 本年 vs 上年净利润增速

| PEG      | 评级    | 操作                       |
|----------|---------|----------------------------|
| < 0.5    | 🥇🥇    | 深度低估 (需 PEG < 1 + ⭐⭐⭐⭐⭐ + Leader ≥ 11) |
| 0.5-1.0  | 🥇      | 重仓                       |
| 1.0-1.5  | 🥈      | 标准                       |
| 1.5-2.0  | 🥉      | 轻仓                       |
| 2.0-5.0  | ⚠️      | 警示, 需强逻辑支撑        |
| > 5.0    | ❌      | 不买 / 减仓                |
```

**纪律:**
- PEG > 2 自动降级
- 卡点 ⭐⭐⭐⭐⭐ + Leader ≥ 11 + PEG < 1.5 → 升 🥇 重仓
- g 可持续性必查 (周期反转 vs 真实增长)
