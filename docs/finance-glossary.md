## 1. 基础术语

### 市值 (Market Cap)

```
公式: 总股本 × 当前股价
例: 立讯精密 总股本 73.16 亿股 × ¥60.90 = ¥4457 亿 = $622 亿
```

**为什么重要**: 所有估值都基于市值, 不是股价。

### 流通市值 vs 总市值

```
总市值 = 公司发行的全部股票 × 股价 (包括大股东锁定股)
流通市值 = 真正在外面流通的股票 × 股价 (除去锁定股, 大股东减持)

立讯精密: 总市值 = 流通市值 = 4457亿 (全流通, 较小公司少见)
```

### EPS (Earnings Per Share, 每股收益)

```
公式: 净利润 / 总股本
立讯精密 EPS = 217.58亿净利润 / 73.16亿股 = ¥2.97 (2026E)
```

**为什么重要**: 所有 PEG (PE / 增速) 都基于 EPS, 不是净利润绝对数。

### 净利润 (Net Income)

公司在一定期间 (通常 1 年) 赚到的钱, 扣除所有成本、税费、利息后的最终收益。

**关键区分**:
- **GAAP 净利润**: 美国会计准则算的
- **Non-GAAP 净利润**: 公司调整后 (剔除一次性项目)
- **扣非净利润**: 扣除非经常性损益
- **核心净利润**: 我们分析时建议用这个 — 排除卖资产/政府补贴等一次性

### ROE (Return on Equity, 净资产收益率)

```
公式: 净利润 / 股东权益
例: 立讯精密 2025A ROE = 21.1% = 每 100 块股东权益, 一年赚 21.1 块
```

**为什么重要**: 衡量公司用股东的钱赚钱的效率。15%+ 优秀, < 10% 警惕。

### PE (Price-to-Earnings Ratio, 市盈率)

```
公式: 股价 / EPS
分类:
  - PE TTM: 股价 / 最近 12 个月实际 EPS (看历史)
  - Forward PE: 股价 / 未来 12 个月预测 EPS (看未来)
立讯精密 PE TTM = 27.21x = ¥60.90 / ¥2.24 (TTM EPS)
```

**为什么重要**: PE 越高, 市场预期公司增长越快; PE 越低, 越"便宜"。

**PE TTM vs Forward PE**:
- TTM 用过去 12 个月真实数据 → 反映历史
- Forward 用未来 12 个月预测 → 反映预期
- 周期股 TTM 容易误导 (周期底部 PE 虚高), 用 Forward PE 更准

### PB (Price-to-Book, 市净率)

```
公式: 股价 / 每股净资产
京东方A PB = 2.52x = ¥9.10 / ¥3.61 (2025A 净资产/股)
```

**为什么重要**: 衡量股价相对公司"账面价值"的高低。资产密集行业 (银行/地产) PB 更重要, 成长股 (科技) PE 重要 PB 次要。

## 2. 估值方法 — 6 大主流

### 方法 1: PE / PEG (相对估值)

```
PE = 股价 / EPS → 越高越贵
PEG = PE / 增速 → ≥ 2 偏贵, ≤ 1 健康
适合: 成长股, 短期估值
不适合: 周期股 (PE 低估其实是顶部反信号)
```

### 方法 2: DCF (绝对估值)

```
DCF = 把未来所有现金流折现到现在
适合: 长期价值评估, 跨周期股
不适合: 早期亏损公司 (现金流为负)
```

### 方法 3: PB / ROE (相对估值)

```
PB = 股价 / 每股净资产
适合: 银行 / 地产 / 重资产
不适合: 轻资产 (软件 / 服务)
```

### 方法 4: EV/EBITDA (并购估值)

```
EV = 市值 + 净债务
EBITDA = 营业利润 + 折旧 + 摊销 (剔除资本结构影响)
适合: 跨公司 / 跨国比较
不适合: 早期亏损公司
```

### 方法 5: P/S (市销率)

```
P/S = 市值 / 营收
适合: 亏损成长股 (如 SaaS 早期)
不适合: 成熟行业 (银行 / 制造)
```

### 方法 6: DDM (股利贴现)

```
DDM = 未来所有股利折现
适合: 高分红蓝筹 (银行 / 公用事业)
不适合: 成长股 (不分红或分红很低)
```

**Mavis 框架默认用 PEG + DCF, 互补用 PB / P/S**.

## 3. DCF 详解 — 这是 Mavis v3/v9 框架的核心

### DCF 一句话

"把公司未来**所有**现金流折现到今天, 就是合理市值"

### DCF 公式拆解

```
公司价值 = Σ (CF_t / (1+r)^t) for t = 1 to ∞
        = 显预测期 + 过渡期 + 永续期

显预测期: 5 年 (公司能可靠预测的窗口)
过渡期: 5 年 (从显预测 → 永续期)
永续期: 永远 (假设永续增长率 g)
```

### DCF 三段解析

```
┌────────────────────────────────────────┐
│ 显预测期 (e1, e2, e3)                   │  ← 估值占比 20%
│ 用 5 家券商平均 EPS 预测                  │
│ 精确但有限 (3-5 年)                       │
├────────────────────────────────────────┤
│ 过渡期 (从显预测 → 永续)                │  ← 估值占比 20%
│ 5 年, 增速从短期 g 衰减                  │
├────────────────────────────────────────┤
│ 永续期 (永远)                            │  ← 估值占比 60-80%!
│ 用永续增长率 g (假设公司永远按这个增速)  │
└────────────────────────────────────────┘
```

**关键观察**: **永续期占比 60-80%**, 也就是说 g 比 e1, e2, e3 更重要!

### DCF 反推 (v3 框架用)

我们 Mavis 不直接算 DCF (因为没 WACC), 而是**反推**:

```
已知:  市值 (实时), e1, e2, e3, WACC
反算:  L = "市场 priced 了多少终局利润"

意义: L/E3 比率 (隐含 L 是 2028E 净利的多少倍)

如果 L/E3 远大于行业 typical → 市场已经透支很多
如果 L/E3 接近行业 typical → 市场预期合理
```

### DCF 隐含 L 的含义

```
L = "市场认为这家公司终局 (10 年后稳态) 能赚多少净利润"

L = 1000 亿, 当前市值 = 1500 亿:
  → 市场 priced 终局利润 1000 亿
  → 市值比 L 高 50%, 是透支

L = 500 亿, 当前市值 = 300 亿:
  → 市场 priced 终局利润 500 亿
  → 市值比 L 低 40%, 是低估
```

### L/可达利润 L 比率 (Mavis v3 标准)

```
可达利润 = "公司在 TAM × 龙头 share × 净利率 框架下, 最合理的稳态年净利"
可达利润 粗估 (以特变电工为例):
  - 变压器 2030 全球 TAM = $500 亿 (AI 数据中心 + 电网升级)
  - 特变市占 ~10-15% = $50-75 亿 = 350-525 亿 RMB
  - 稳态净利率 10% × 营收 1500 亿 = 150 亿 RMB

如果 L = 80 亿 (校正 DCF L), 可达 = 200 亿:
  L/可达 = 0.40x ← 严重低估, 加仓候选

如果 L = 600 亿, 可达 = 200 亿:
  L/可达 = 3.0x ← 严重透支, 减仓
```

### DCF 校正 (r=10% × 0.7)

```
Mavis 用 r = 8%, 10%, 12% 三档折现率
"校正" 公式: 校正 L = L(10%) × 0.7

为什么 0.7: 学术研究表明 r=10% 算的 L 系统偏高 30-43%
        乘 0.7 是基于 Damodaran NYU 的实证调整
        校正后 = 最接近市场隐含真实水平
```

## 4. WACC 详解 — 折现率

### 一句话定义

```
WACC = 公司"为融资付出多少钱"
     = 股东要多少回报 + 银行要多少利息 加权平均
```

### WACC 公式

```
WACC = (E/V) × Re + (D/V) × Rd × (1-T)

E = 股权市场价值 (市值)
D = 债务账面价值 (有息负债)
V = E + D (总资本)
Re = 股权成本 = Rf + β × (R_m - R_f)
Rd = 债务成本 (公司借款利率, 抵税后)
T = 税率
```

### 四个组成部分

| 符号 | 含义 | Mavis typical |
|---|---|---|
| **Rf** (无风险利率) | 10 年国债收益率 | 中国 ~2.3% |
| **β** (股票贝塔) | 个股 vs 大盘波动率 | 半导体设备 1.2-1.5, 公用事业 0.5 |
| **(R_m - R_f)** = ERP | 股权风险溢价 | A 股 ~6.7% |
| **Rd** (债务成本) | 公司借款利率 | ~4.5%, 抵税后 3.4% |
| **T** (税率) | 企业所得税 | 25% (高新企业 15%) |

### WACC 计算示例 (特变电工理论)

```
假设:
  E/V = 0.7 (股权占 70%) — 全流通, 低杠杆
  D/V = 0.3 (债务占 30%)
  Rf = 2.3%, β = 1.0 (电力设备典型), ERP = 6.7%
  Rd = 4.5%, 抵税后 3.4%
  T = 25%

Re = 2.3% + 1.0 × 6.7% = 9.0%
Rd × (1-T) = 3.4%
WACC = 0.7 × 9.0% + 0.3 × 3.4% = 6.3% + 1.0% = 7.3%

但 Mavis 用 行业 typical 10% (杠杆更高的公司) — 略保守
```

### WACC 越大 → 估值越低 (敏感性方向)

```
特变电工:
  WACC = 9%  → DCF 估值 ¥27
  WACC = 10% → DCF 估值 ¥22 (-19%)
  WACC = 11% → DCF 估值 ¥18 (-36%)

↑ WACC ↑, ↓ 估值 ↓
```

## 5. g — 永续增速详解

### 一句话定义

```
g = 公司过了显预测期之后, 永远年的年化增长率
```

### 公式

```
永续期价值 = FCF_末 × (1 + g) / (WACC - g)  ← Gordon Growth Model
```

### g 的合理范围

```
g = 0%    → 公司成熟稳态, 没有增长
g = 1-2%  → 衰退行业 (传统制造)
g = 2-3%  → 中国 GDP long-term, 成熟市场
g = 3-5%  → 成长行业 (适度)
g = 5-10% → 高速成长 (早期 SaaS)
g > WACC  → 公式发散 (无意义)
```

**关键规则**: g 必须小于 WACC, 否则公式无意义

### g 怎么估

```
1. 中国 GDP 长速 (国务院 + IMF 数据):  2-3% → 起点
2. 加行业 share 调整:
   行业还有空间 (top 5 龙头 +5%) → g 高
   行业已饱和 (top 1 占 30% +0%) → g 低
3. 加公司生命周期:
   早期 + 高速 (8-10%), 成熟 (2-3%), 衰退 (0-1%)
```

### Mavis 用法

```python
# 我们不用动态公式, 直接 hardcode by 板块
"半导体设备":   0.030,  # 3% (行业有空间 + 中国 GDP)
"新能源":      0.035,  # 3.5% (政策驱动)
"消费电子代工": 0.030,  # 3% (成熟 + Apple 链)
"AI 芯片":      0.050,  # 5% (早期高增长溢价)
```

### g 越大 → 估值越高

```
特变电工:
  g = 2%  → DCF 估值 ¥20 (-9%)
  g = 3%  → DCF 估值 ¥22 (typical)
  g = 4%  → DCF 估值 ¥27 (+23%)

↑ g ↑, ↑ 估值 ↑
```

### 永续期权重 = 60-80%

为什么 g 这么重要:
- 显预测期 3-5 年 (e1, e2, e3) 加起来 ≈ DCF 总值的 20%
- 过渡期 5 年 ≈ 20%
- **永续期永远 ≈ 60%**
- 这意味着 g 即使错 1%, 估值就差 10-15%

## 6. FCF 详解 — 自由现金流

### 一句话定义

```
FCF = 公司能"自由花"的现金 ≠ 净利润

FCF = 经营性现金流 (OCF) - 资本支出 (CapEx)
```

### FCF vs OCF vs NI

```
OCF (经营性现金流) = 公司日常经营收到 - 付出 (真金白银)
NI  (净利润)    = 会计上"赚到"的钱 (含应收/存货变更)
FCF (自由现金流) = OCF - CapEx (扣除买设备的钱)

例: 立讯精密 (重资产)
  NI = ¥218 亿 (2026E 预测)
  OCF = NI × 0.92 = ¥200 亿 (OCF < NI, 因为很多应收)
  FCF = OCF × 0.96 = ¥192 亿 (再扣 CapEx)
```

### FCF 三种算法 (等价)

```
算法 1 (简化): FCF = NI × FCF_factor
  (粗估, 适合估值; FCF_factor 按板块)

算法 2 (中): FCF = OCF - CapEx
  (需要 OCF 数据 = 净利润 + D&A - ΔWC)

算法 3 (精确): FCF = EBIT × (1-T) + D&A - CapEx - ΔWC
  (需要 OCF 三表, 工作量大)
```

### FCF_factor = NI / OCF (粗估系数)

```
行业 typical (A 股实证, CSMAR 数据库):

  行业           FCF_factor (NI → FCF)
  ──────────────────────────────────────
  资本密集 (面板/钢铁)   0.55-0.65  (CapEx 巨大)
  半导体设备 (重)         0.75-0.85
  消费电子 (Apple链)      0.85-0.95
  医药/品牌 (轻资产)      1.00-1.20  (OCF ≥ NI)
  软件/SaaS              1.20-1.40
  金融 (银行)            1.00-1.10
```

### 巴菲特最看重 OCF / NI 比率

```
公式: OCF / 净利润 (>100% 为佳)

立讯精密   OCF/NI ≈ 0.92  (略低, 重资产代工)
北方华创   OCF/NI ≈ 1.20  (健康, 设备有预收款)
京东方A    OCF/NI ≈ 0.55  (差, 面板 CapEx 巨大)
茅台       OCF/NI ≈ 1.10  (健康, 品牌有预收款)
```

OCF < NI **持续** 3 年以上 → 警惕 (利润是应收堆积)

## 7. 4×4 敏感性矩阵 — 怎么读

### 矩阵是什么

```
DCF 输出 = 16 个估值格 (WACC 4 档 × g 4 档)

示例 (特变电工):
| WACC \ g | g=2% | g=3% | g=4% | g=5% |
|----------|------|------|------|------|
| WACC=9%  | ¥22  | ¥24  | ¥28  | ¥32  |  ← 乐观格 (左上)
| WACC=10% | ¥20  | ¥22  | ¥24  | ¥28  |  ← typical (中间)
| WACC=11% | ¥19  | ¥20  | ¥22  | ¥24  |
| WACC=12% | ¥17  | ¥18  | ¥20  | ¥22  |  ← 悲观格 (右下)

⭐ (typical) = WACC=10%, g=3% 的中位估值
```

### 怎么读矩阵

```
位置 1: 左上 (低 WACC + 高 g) → 乐观假设
        → 估值最高
        → 只有在极端乐观假设下成立

位置 2: 右下 (高 WACC + 低 g) → 悲观假设
        → 估值最低
        → 只有极端悲观假设下成立

位置 3: 中间 (typical) → 现实最可能
        → 估值反映市场共识

你的股价 ¥22:
  → 落在右上 WACC=10% / g=3% 附近
  → 估值反映 typical 假设
  → 不极端低估, 不极端高估
```

### 矩阵的 3 种用法

```
用法 1: 区间估值 (粗)
  "DCF 估值 ¥17-32, 当前价 ¥22 在区间内"
  → 估值合理 (不便宜不贵)

用法 2: 概率加权 (细)
  给每个 16 格一个概率权重, 算加权估值
  → 这是 v8 框架的概率加权

用法 3: 风险检查 (关键)
  16 格里"最不利的 4 格"是底部风险
  → 看这 4 格平均价 (估值下限)
  → 看这 4 格平均价 (估值上限)
```

## 8. PEG 详解 — 4 件套 (v4 框架)

### PEG 公式

```
PEG = PE / 增速 (%)

例: 立讯精密 PE 14.7, g 27.7%
PEG = 14.7 / 27.7 = 0.53 ✅ (健康)

PEG < 1 健康, < 0.5 超便宜, > 2 偏贵, > 3 极贵
```

### v4 4 PEG 件套 — 4 个口径

```
口径 1: PEG_A (本财年, 后视镜, Lynch 经典)
  - Forward PE = P / E1
  - g = (E1/E0 - 1) × 100%
  - PEG_A = Fwd PE / g_A

口径 2: PEG_C (下一财年, 前视镜)
  - Forward PE = P / E2
  - g = (E2/E1 - 1) × 100%
  - PEG_C = Fwd PE / g_C

口径 3: PEG_真实 (稳态 CAGR, ✅ 决策依据)
  - Forward PE = P / E1
  - CAGR = (E3/E0)^(1/3) - 1
  - PEG_真实 = Fwd PE / CAGR

口径 4: PEG_表观 (NTM YoY)
  - Forward PE = P / E1
  - g_NTM = (E1/E0 - 1) × 100%
  - PEG_表观 = Fwd PE / g_NTM

PEG_A 数值 = PEG_表观 数值 (数学相同, 不同标签)
```

### 为什么 4 件套? — 失真检测

```
案例: 江波龙 v3 失真
  curl 返回: 2026E EPS 32.716, 2025A 3.364
  g_NTM = (32.716/3.364 - 1) × 100% = 872%  ← 假"超快速增长"
  Fwd PE = 599/32.716 = 18x
  PEG_A = 18/872 = 0.02x ← "看起来超便宜!"
  
  但是:
  - 净利率从 6% 跳到 35% (5x 跳跃)
  - 这不是真实增长, 是数据异常
  
  PEG_真实 用 CAGR (含 2026E → 2028E 下降):
    CAGR = (26.514/3.364)^(1/3) - 1 = 99%
  PEG_真实 = 18/99 = 0.18x  ← 还是便宜
  But用 2025A EPS 反推 PEG:
    PEG_真实 (用 2025A) = 178/99 = 1.80x  ← 偏贵!

教训:
  - 单一 PEG_A = 0.02x 是诱饵
  - 必须看 4 件套, 对比 PEG_A vs PEG_真实
  - PEG_A vs PEG_真实 差距大 → 失真信号
```

### 失真检测规则

```
信号 1: NTM 净利率 vs 历史均值
  - 跳跃 > 3x → 数据异常
  - 例: 江波龙 6% → 35% (5x) → ⚠️ 失真

信号 2: PEG_A vs PEG_真实 大幅偏离
  - PEG_A = 0.02x 但 PEG_真实 = 1.80x
  - 说明 PEG_A 的 g_NTM 极度虚高 → 失真

信号 3: E2 < E1 (增速反转)
  - 江波龙 E1 = 137 亿, E2 = 115 亿, E3 = 111 亿
  - 跌回去 → 周期顶部
  - PEG_A = 0.02x 但 PEG_C = N/A (g_C ≤ 0)
```

## 11. 数学概念速查

### CAGR (年化复合增长率)

```
CAGR = (V_end / V_start) ^ (1/n_years) - 1

例: 特变电工 EPS 2025A 1.18 → 2028E 2.45 (3 年)
CAGR = (2.45/1.18)^(1/3) - 1 = 1.077^0.333 - 1 = 27.7%
```

**为什么用 CAGR 不用年算术平均**:
- 算术平均: 27% × 3 年累计 81%
- CAGR: (2.45/1.18)^(1/3) - 1 = 27.7% 累计 1.277^3 = 2.08x
- CAGR 反映**复利**, 真实增长

### PE-Band (估值通道)

```
PE 历史区间 = [PE_min, PE_max]

当前 PE 位置 = (PE_today - PE_min) / (PE_max - PE_min)
P/E Band 是相对估值的稳定方法

PE 历史最大 / 当前 = 估值便宜 (历史顶部偏离大)
PE 历史最小 / 当前 = 估值贵 (历史底部偏离大)
```

### 标准差 / Z 分数

```
标准差 σ = 平均值附近波动的范围
  - 1σ 内 = 68% 数据
  - 2σ 内 = 95%
  - 3σ 内 = 99.7%

Z 分数 = (值 - 平均) / σ
  Z = 0    → 处于平均
  Z = 2    → 偏离 2σ
  Z = -2   → 偏离 -2σ
```

**SUE 用 Z 分数标准化超预期**:
```
SUE = (实际 EPS - 一致预期 EPS) / 历史预测偏差标准差
SUE = 0   → 符合预期
SUE = +2  → 大幅超预期 (强买入信号)
SUE = -2  → 大幅不及预期 (强卖出)
```

### 永续期 vs 显预测期权重

```
永续期估值 = FCF_末 × (1+g) / (WACC - g)  /  (1+WACC)^N

如 N=3 (显预测期 3 年), WACC=10%, g=3%:
  显预测期权重 ≈ 1 - 1/(1+0.10)^3 ≈ 25%
  过渡期 (5 年)  ≈ 35%
  永续期 (永远)  ≈ 40%

合理 DCF 中:
  显预测期 ≈ 20-30%
  过渡期     ≈ 20-25%
  永续期 (永远) ≈ 50-60%
```

## 12. 叙事切换 + PE 重估 (新增, 2026-07-03)

### 12.1 什么是叙事切换

**叙事 = 市场讲的故事** (公司应该被怎么看)
**切换 = 故事从 A 变成 B, 估值锚点随之改变**

```
叙事切换类型 (A 股常见):
  1. 行业身份切换 (例: 海光 CPU 厂商 → DC 算力核心)
  2. 客户结构切换 (例: 立讯 Apple 代工 → AI 服务器 ODM)
  3. 业务重心切换 (例: 特变电力设备 → AI 数据中心卖水)
  4. 概念切换 (例: 传统制造 → 国产替代)
```

### 12.2 估值切换的数学

```
旧叙事: PE = 12x (传统行业 typical)
新叙事: PE = 25x (AI 主线 typical)

估值贡献: 25 / 12 = 2.08x (+108%)

加上业绩 1.5-2x 增长:
  翻番 = 估值 2x × 业绩 1.5x = 3x (2 年)
  或 估值 1.4x × 业绩 1.5x = 2.1x (2 年)
```

### 12.3 触发条件 (估值切换需要 4 维全满足)

```
维度 1: 业绩驱动
  - 一致预期 EPS 5 年 CAGR ≥ 15% (否则没业绩支撑, 切换是泡沫)

维度 2: 估值切换 (⭐ 关键)
  - 当前 PE < 历史 50% 分位 (留有扩张空间)
  - 切换后 PE 可达历史 80-90% 分位
  - 触发: AI/新能源/国产替代 catalyst 明确

维度 3: 板块 β
  - 在 AI/新能源/半导体/机器人/稀土主线上
  - 板块里有 AI 配套业务 或 主线直接相关

维度 4: 龙头地位
  - 卡点 ⭐⭐⭐⭐+
  - 龙头评分 ≥ 11/14
  - 不可替代性 (top 1-3)
```

### 12.4 估值切换的常见陷阱

```
陷阱 1: 切换没兑现
  - 叙事讲得动听, 但订单/业绩没兑现
  - 估值回吐, 跌回原 PE
  - 例: 部分公司讲"AI 配套" 多年, 实际 AI 营收 < 5%

陷阱 2: 切换到位后估值已 Priced
  - 切换前: PE 12x (留 2x 空间)
  - 切换后: PE 25x (空间已用完)
  - 后期加仓无空间, 只能吃业绩

陷阱 3: 切换叙事破裂
  - AI 泡沫破裂 / 国产替代受挫
  - 估值从 25x 跌回 12x = -52% 跌幅
  - 教训: 估值切换需要 catalyst 持续兑现, 否则会快速反转
```

### 12.5 实战: 怎么找估值切换翻番

```bash
# Step 1: 看 PEG 健康 (业绩驱动基本)
# Step 2: 看 PE 历史分位 < 50% (留有扩张空间)
# Step 3: 看板块 β (在 AI/新能源/半导体/机器人 主线上)
# Step 4: 看龙头评分 ≥ 11/14 (不可替代)
# 4 维全 ✅ = 估值切换型翻番候选 (5 年 2x 概率 30-50%)

# 实操工具: Mavis v9.1 板块-aware DCF + v6 翻 N 倍框架
# (待 v6.2 升级: 加估值切换维度)
```

### 12.6 估值切换 vs 业绩驱动 (终极对比)

| 维度 | 业绩驱动翻番 | 估值切换翻番 |
|---|---|---|
| 谁主导 | 公司基本面 (EPS 增长) | 市场情绪 (PE 扩张) |

## 13. WACC / FCF / g 组合实操 (新增, 2026-07-04)

> 前置依赖: §3 DCF 详解 + §4 WACC + §5 g + §6 FCF
> 章节来源: 用户提问"这三参数举例 + 用途" → 整理
> 工具关联: `tools/double_screen.py` 直接读 `tools/factors/valuation/dcf_engine.py` 里的硬编码

### 13.1 三参数一句话 + 例子

| 参数 | 一句话 | 数字例子 (胜宏科技 300476) |
|---|---|---|
| **WACC** | 公司融钱的平均成本 → DCF 折现率 | 半导体设备 typical = **11%** |
| **FCF_factor** | 净利润 → 自由现金的折损比率 | 半导体设备 typical = **0.80-0.85** |
| **g** | 永续增长率 (公司长期能涨多快) | 中国 GDP 兜底 = **3-4%** |

### 13.2 FCF 怎么从净利润算出来

```
胜宏科技 300476 粗估 (2024 年):
  净利润 (NI)         = ¥25 亿
+ 折旧摊销 (D&A)      = ¥3 亿    ← 加回 (不是真现金流出)
- 资本支出 (CapEx)     = ¥8 亿    ← 扣 (买新设备/扩产)
- 营运资金增加 (ΔWC)   = ¥2 亿    ← 扣 (应收账款/存货增加)
─────────────────────────────────
= FCF                  ≈ ¥18 亿

FCF_factor = 18 / 25 = 0.72 (略低于行业 0.80-0.85 的 typical)
            ← 说明这家公司当前扩产比同业更激进 (要把未来产能砸出来)
```

**FCF_factor 行业 typical (来自 `tools/factors/valuation/dcf_engine.py`):**
- 半导体设备: 0.80-0.85
- 消费/家电: 0.88
- 半导体 (晶圆/设计): 1.20 (现金流好, 因为轻资产)

### 13.3 DCF 三段公式 (实操版)

```
公司价值 = 显预测期 (前 3 年) + 过渡期 (第 4-8 年) + 永续终值 (永远)
        = Σₜ₌₁³ FCFₜ / (1+WACC)ᵗ
        + Σₜ₌₄⁸ FCF₈ × (1+g_transition)ᵗ⁻³ / (1+WACC)ᵗ
        + [FCF₈ × (1+g) / (WACC - g)] / (1+WACC)⁸
```

**代入胜宏科技数字 (举例):**

```
假设第 8 年 FCF = ¥80 亿
WACC = 10%, g = 4%
─────────────────────────────────────────────────────────
终值 (TV) = 80 × (1.04) / (0.10 - 0.04) = ¥1387 亿  ← 永续期
折回今天 = 1387 / 1.10⁸ = ¥615 亿
─────────────────────────────────────────────────────────
对比当前市值 ¥308 亿 → 内在价值 ≈ 2x 当前 → 翻番空间存在 ✅
```

### 13.4 g 敏感性 (这一数字最敏感, 改 1% 估值差 30%)

| g | 终值 (TV) | 折现到今天 | 估值变化 |
|---|---|---|---|
| 3% | ¥1039 亿 | ¥461 亿 | -25% |
| 4% | ¥1387 亿 | ¥615 亿 | typical |
| 5% | ¥2240 亿 | ¥994 亿 | +62% |

**实战规则:**
- g 不能 > WACC (否则公式发散, 无意义)
- g 不能 > 长期 GDP 增速 (公司不可能永远比全国涨得快)
- 真保守估值 = WACC 给上限 + g 给下限 (双杀)

### 13.5 三参数决定什么 + 怎么读 (一句话总结)

| 你想判断 | 看 | 怎么读 |
|---|---|---|
| 公司风险大不大 | **WACC** | 高 → 估值给低 (折现狠) |
| 公司赚的是真钱还是账面钱 | **FCF_factor** | < 0.8 → 警惕 (重资产/扩产烧钱) |
| 公司永续能不能涨 | **g** | > 5% → 警惕 (终局不能超 GDP) |
| 估值保守不保守 | **WACC + g 都用上限** | 真保守 = WACC +1% 且 g -1% |
| L / 可达利润 是叙事透支还是低估 | **三参数组合** | L/可达 < 0.8 ✅ / > 2 ❌ |

### 13.6 为什么 Mavis 反算 DCF L (而不是直接估 DCF)

```
直接算 DCF 的痛点:
  - 不知道精确 WACC (用行业 typical 误差 ±2%)
  - 不知道 g 该给多少 (3%? 4%? 5%? 差很多)
  - 预测 FCF 本身就有误差 (5 年后谁知道)

我们 Mavis 反推 L:
  - 已知: 当前市值 (实时 curl), 未来 3 年一致预期 e1/e2/e3 (curl)
  - 假定: WACC/FCF_factor/g 都是行业 typical (硬编码)
  - 反算: 市场要把这家公司未来做成"年净利润多少亿"才撑得起当前市值
  - 这个 L 就是"市场已经 priced 的终局预期"
  - 然后比较 L vs 可达利润 (粗估营收天花板 × 真实净利率)
```

**判断叙事透支:**
```
L / E3 快筛:
  < 2   → 市场预期温和, 叙事未满
  2-5   → 较高预期, 需验证
  > 5   → 叙事已饱满, 警惕

L / 可达利润 (核心):
  < 0.8  → 叙事低估 ✅
  1-2   → 合理
  > 2    → 叙事透支 ❌
```

### 13.7 板块 hardcode 速查 (Mavis 默认假设)
