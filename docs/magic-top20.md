## 📖 怎么读

1. **ROC (Return on Capital)** = 资本回报率, 越高越好 — 公司赚钱效率
2. **EY  (Earnings Yield)** = 盈利收益率, 越高越好 — 股价相对盈利能力便宜
3. **综合排名** = ROC + EY 联合排名, 越小越靠前 (双优)
4. **行业过滤** = 银行/保险/地产/公用等不参与 (ROC/EY 在这些行业失真)
