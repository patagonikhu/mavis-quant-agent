## 字段说明

| 字段 | 公式 | 含义 |
|---|---|---|
| 营收 yoy (本季) | `or_yoy` | 本季营业总收入同比 |
| 营收 yoy (上季) | `LAG(or_yoy, 1)` | 上一季同比 |
| 营收 yoy (上 2 季) | `LAG(or_yoy, 2)` | 上 2 季同比 |
| 净利 yoy | `netprofit_yoy` | 净利润同比 (Tushare VIP 无扣非 yoy) |
| 毛利率 | `grossprofit_margin` | 单季毛利率 |
| 毛利率 (去年同期) | `LAG(grossprofit_margin, 4)` | 同比基准 |
| EBIT | `ebit / 1e8` | 当前季 EBIT (亿) |
| 4 季增量 | `(ebit - ebit_4q_ago) / 1e8` | 业务规模真实扩大 |
| ROE | `roe` | 净资产收益率 |
| PE | `pe` (stk_factor 最新一日) | 静态市盈率 |
| PE_TTM | `pe_ttm` | TTM 滚动市盈率 |
| 市值 | `total_mv / 1e4` | 总市值 (亿) |

## R3 启动期反转信号

对每只命中的票 (每季), 验证 4 个条件:
- 1. 营收 yoy >= 25% (主业高增长)
- 2. 净利 yoy >= 50% (盈利高增长)
- 3. 毛利率 同比 + 环比 双升 (议价能力提升)
- 4. **净利 yoy 跳升 >= 50pp** (本季 - 上季, 业务反转关键信号)

**位置过滤 (默认开启)**: 距 1 年低点 <= 200% 且 距 1 年高点 >= -30% (排除追顶 + 严选启动期)

**为什么用跳升 50pp**: 10x 票起涨季 (T+0) 净利 yoy 中位 41% / 跳升中位 50pp+, 旧"3 季 EBIT 累计 >= 2x" 在 T+0 0% 命中。跳升 50pp 在 T+0 41% 命中。

## 4 条件门槛

- 营收 yoy >= 25.0%
- 净利 yoy >= 50.0%
- 毛利率 当前 > 上季 (环比升) **AND** 毛利率 当前 > 去年 (同比升)
- 净利 yoy 跳升 >= 50pp (本季 - 上季)

- (ROE 门槛已移除, R3 算法不依赖 ROE)
